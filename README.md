# STM32 – W5500 Ethernet Communication
This repository contains documentation and software related to Ethernet communication on the **STM32 Nucleo-G474RE** platform using the **W5500** hardware module.

The project includes:
- **Firmware for STM32** implementing SPI-based communication with the W5500 Ethernet controller.
- A **basic Python script** that connects to the microcontroller using the **NaMi protocol**, enabling simple data exchange and verification of network functionality.
